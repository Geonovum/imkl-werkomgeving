**Toelichting op Inspire schemas.**

De IMKL-GML schemas importeren Inspire schemas. De referenties naar deze Inspire schemas zijn in de IMKL schemas opgenomen. De werking van deze schemas is gebaseerd op een continue online beschikbaarheid van deze schemas. Omdat Geonovum deze schemas niet in beheer heeft is er als 'serviceproduct' een kopie gemaakt van deze schemas. Deze schemas moeten uitdrukkelijk als kopie en dus niet als het origineel worden beschouwd.

Voor de OGC GML schemas is geen kopie opgenomen.

**De volgende IMKL versies maken gebruik van deze set aan Inspire schemas:**

IMKL1.2
IMKL2.0
IMKL3.0

**Opmerking bij het Inspire schema voor Telecom.**
Het TelecommunicationsNetwork.xsd wordt niet meer gehost op de in het IMKL schema aangegeven url. Omdat Telecom niet als thema opgenomen is in de Inspire richtlijn wordt die apart gepubliceerd als draft in een github repository.
